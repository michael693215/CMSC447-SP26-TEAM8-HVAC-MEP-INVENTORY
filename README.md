  The Inventory Management System is a full-stack web application developed by Charles Dang, Ellis Hale, and Michael Obinomen. The system is designed to support the operational needs of our stakeholder, William’s company, by centralizing the tracking of parts and materials across multiple physical locations. As fully implemented in Sprint 3, the application covers eight functional modules accessible from a role-aware dashboard: Inventory, Log Delivery, Delivery History, Purchase Orders, Materials Requests, Contact List, Locations, and About. The inventory module supports item-level detail views with per-product delivery linkage. Delivery and purchase order records are stored using a hybrid approach with both front and backend storage, while authentication is handled server-side via Supabase Auth. The system currently operates as a single-tenant web application serving one organization's field and office staff, with no external payment, map, or third-party API integrations beyond Supabase and Docupipe.
